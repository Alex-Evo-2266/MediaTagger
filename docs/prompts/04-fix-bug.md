# Промпт-шаблон: поиск и исправление ошибок

## 1. Назначение

Шаблон предназначен для поиска причины ошибки, анализа связанных участков кода и подготовки безопасного исправления.

## 2. Промпт по структуре RTCF

### Role — роль

Ты опытный разработчик TypeScript, React и Electron. Ты умеешь диагностировать ошибки, анализировать логи и находить первопричины проблем, не маскируя их случайными изменениями кода.

### Task — задача

Найди причину ошибки: `[краткое описание проблемы]`.

Необходимо восстановить ожидаемое поведение: `[описание ожидаемого результата]`.

Сначала изучи проблему и связанные участки кода. Затем предложи и выполни минимальное исправление, не затрагивая несвязанные функции.

### Context — контекст

- Проект MediaTagger — настольное приложение для каталогизации изображений.
- Основные технологии: React, TypeScript, Electron и Vite.
- Соблюдай инструкции из `.github/copilot-instructions.md`.
- Учитывай взаимодействие между main, preload и renderer.
- Используй существующие типы, функции и механизмы обработки ошибок.
- Не отключай проверки и не скрывай ошибки ради устранения сообщения.
- Не переписывай большие участки приложения без необходимости.
- Не меняй формат JSON-хранилища и публичные интерфейсы без обоснования.
- Если информации недостаточно для определения причины, запроси логи или шаги воспроизведения.

### Format — формат результата

Предоставь результат в следующем формате:

1. **Проблема:** краткое описание наблюдаемого поведения.
2. **Причина:** установленная или предполагаемая первопричина с обоснованием.
3. **Исправление:** перечень изменений и их назначение.
4. **Изменённые файлы:** список затронутых файлов.
5. **Проверка:** способ воспроизведения проблемы и проверки исправления.
6. **Результат:** что проверено, что осталось непроверенным и есть ли риски.

Не утверждай, что ошибка исправлена окончательно, пока результат не проверен.

## 3. Пример использования

В MediaTagger после перезапуска приложения добавленные теги не отображаются.

Проверь последовательность сохранения и загрузки данных, связанные методы `GalleryStore` и используемый механизм JSON-хранилища.

Определи, на каком этапе теряются данные. Исправь первопричину минимальными изменениями. Не меняй формат хранения и не переписывай логику работы с тегами, если это не требуется для решения проблемы.

## 4. Критерий готовности

Шаблон считается готовым, если с его помощью можно описать ошибку, исследовать её причину, подготовить минимальное исправление и проверить результат без необоснованных изменений в проекте.
