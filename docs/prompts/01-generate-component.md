# Промпт-шаблон: генерация компонента или функции

## 1. Назначение

Шаблон предназначен для создания нового React-компонента или TypeScript-функции в проекте MediaTagger.

## 2. Промпт по структуре RTCF

### Role — роль

Ты опытный frontend-разработчик, работающий с React и TypeScript. Ты умеешь разрабатывать компоненты для настольных приложений на Electron и придерживаешься существующей архитектуры проекта.

### Task — задача

Создай компонент или функцию `[название]`, которая выполняет следующую задачу: `[описание необходимого поведения]`.

Перед реализацией изучи существующий код и определи, где лучше разместить новую функциональность.

### Context — контекст

- Проект MediaTagger — настольное приложение для каталогизации изображений.
- Основные технологии: React, TypeScript, Electron и MUI.
- Соблюдай инструкции из `.github/copilot-instructions.md`.
- Используй существующие типы, компоненты и функции, если они подходят для задачи.
- Соблюдай правила форматирования и именования проекта.
- Не добавляй новые библиотеки без необходимости.
- Не изменяй несвязанные части приложения.
- Если требований недостаточно, сначала задай уточняющий вопрос.

### Format — формат результата

Предоставь результат в следующем формате:

1. Кратко опиши назначение компонента или функции.
2. Укажи файл, в котором следует разместить реализацию.
3. Приведи код или внеси необходимые изменения в проект.
4. Перечисли изменения в других файлах, если они потребовались.
5. Укажи, какие проверки необходимо выполнить.
6. Отдельно сообщи о проблемах или ограничениях, которые остались.

## 3. Пример использования

Создай компонент `TagChip` для отображения тега изображения в MediaTagger.

Компонент должен:
- отображать название тега;
- использовать MUI;
- принимать название тега через типизированные props;
- поддерживать обработчик удаления тега;
- корректно работать, если обработчик удаления не передан.

Сначала изучи существующие типы тегов и похожие компоненты. Если в проекте уже есть подходящее решение, используй его вместо создания дубликата. Не изменяй логику хранения тегов.

## 4. Критерий готовности

Шаблон считается готовым, если его можно использовать повторно для генерации разных компонентов или функций путём замены названия и описания задачи, а результат соответствует архитектуре и правилам MediaTagger.
