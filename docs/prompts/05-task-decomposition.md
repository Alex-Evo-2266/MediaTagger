# Промпт-шаблон: декомпозиция сложной задачи

## 1. Назначение

Шаблон предназначен для разделения сложной задачи разработки на небольшие последовательные этапы с понятными результатами и критериями готовности.

## 2. Промпт по структуре RTCF

### Role — роль

Ты опытный технический аналитик и разработчик TypeScript-приложений. Ты умеешь анализировать требования, определять зависимости между компонентами и составлять последовательный план реализации.

### Task — задача

Разбей следующую задачу на отдельные этапы: `[описание задачи]`.

Цель: получить план, по которому можно последовательно реализовать функциональность и проверить результат каждого этапа.

На этом этапе не изменяй код — сначала подготовь план.

### Context — контекст

- Проект MediaTagger — настольное приложение для каталогизации изображений.
- Основные технологии: Electron, React, TypeScript и Vite.
- Соблюдай инструкции из `.github/copilot-instructions.md`.
- Перед составлением плана изучи текущую реализацию и связанные файлы.
- Учитывай разделение приложения на main, preload и renderer.
- Определи зависимости между этапами и порядок их выполнения.
- Старайся использовать существующие механизмы и компоненты.
- Не предлагай масштабную переработку архитектуры, если задачу можно решить локальными изменениями.
- Если требования неоднозначны, сначала задай уточняющие вопросы.

### Format — формат результата

Предоставь результат в следующем формате:

1. **Цель:** краткое описание конечного результата.
2. **Анализ:** какие части приложения затрагивает задача.
3. **Этапы:** не менее трёх последовательных этапов реализации.
4. **Для каждого этапа:**
   - цель;
   - предполагаемые файлы и компоненты;
   - необходимые изменения;
   - зависимости от предыдущих этапов;
   - критерий готовности.
5. **Риски:** возможные проблемы и способы их предотвращения.
6. **Проверка:** как убедиться, что итоговая функциональность работает.

После согласования плана сформулируй отдельный промпт для выполнения каждого этапа.

## 3. Пример использования

Разбей задачу добавления фильтрации изображений по тегам в MediaTagger на последовательные этапы.

Учти:
- существующую модель тегов;
- работу `GalleryStore`;
- передачу данных между процессами Electron, если она потребуется;
- отображение фильтра и результатов в React;
- сохранение существующей функциональности галереи.

Сначала изучи текущую реализацию и подготовь план минимум из трёх этапов. Для каждого этапа укажи критерий готовности. Не изменяй код до согласования плана.

## 4. Критерий готовности

Шаблон считается готовым, если с его помощью можно разделить сложную задачу на последовательные этапы, определить зависимости и проверить результат каждого этапа отдельно.
