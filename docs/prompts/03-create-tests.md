# Промпт-шаблон: создание тестов

## 1. Назначение

Шаблон предназначен для подготовки тестов, которые проверяют корректность работы функций, компонентов и модулей MediaTagger.

## 2. Промпт по структуре RTCF

### Role — роль

Ты опытный разработчик TypeScript и React, который занимается тестированием приложений и поиском ошибок. Ты умеешь выявлять граничные случаи и проверять корректность работы существующего кода.

### Task — задача

Подготовь тесты для `[название функции, компонента или модуля]`.

Необходимо проверить следующие сценарии: `[перечень ожидаемых сценариев]`.

Перед написанием тестов изучи реализацию и определи, какие проверки необходимы.

### Context — контекст

- Проект MediaTagger — настольное приложение для каталогизации изображений.
- Основные технологии: React, TypeScript и Electron.
- Соблюдай инструкции из `.github/copilot-instructions.md`.
- Сначала проверь, какие инструменты тестирования уже установлены и настроены.
- Используй существующую тестовую инфраструктуру, если она есть.
- Не устанавливай новые библиотеки без необходимости и согласования.
- Учитывай существующие типы, зависимости и архитектуру приложения.
- Тесты должны проверять наблюдаемое поведение, а не только внутреннюю реализацию.
- Не изменяй основной код приложения только ради прохождения тестов без объяснения причины.

### Format — формат результата

Предоставь результат в следующем формате:

1. Кратко опиши, что необходимо проверить.
2. Перечисли тестовые сценарии, включая граничные случаи.
3. Укажи расположение тестовых файлов.
4. Подготовь тесты с учётом существующей инфраструктуры.
5. Объясни, как запустить тесты.
6. Укажи, запускались ли тесты и какие результаты получены.
7. Если инфраструктуры тестирования нет, предложи минимальный вариант её организации до установки зависимостей.

## 3. Пример использования

Подготовь тестовые сценарии для добавления тегов в `GalleryStore`.

Проверь:
- добавление нового тега;
- обработку повторного добавления тега;
- обработку некорректных входных данных;
- сохранение ожидаемого состояния после операции.

Сначала изучи реализацию `GalleryStore`, существующие типы тегов и доступные инструменты тестирования. Не устанавливай новые зависимости и не изменяй формат JSON-хранилища без необходимости.

## 4. Критерий готовности

Шаблон считается готовым, если с его помощью можно подготовить тесты для разных частей MediaTagger, определить порядок их запуска и получить достоверную информацию о результатах проверки.
